- Stop-hook reply gate (CW-20261114-0013 PR2): worker Claude sessions with the gate on get a `Stop` hook
  (`tether-worker hook stop-gate`) that asks the hub `tether_pending_replies` over `/mcp` with the session's agent token
  and blocks the turn's end while a typed message younger than 24 hours waits on the seat's reply, naming the messages and
  `tether_message_post`. Each message blocks at most one stop (ids kept in the session's `stop-gate.state`). Never gates
  a continuation stop; fails open on any error or panic. Off by default:
  `catalog.defaults.stop_gate` and per-agent `stop_gate:`; the hub sends it only to workers advertising `stop-gate`.
- Settle rule (CW-20261114-0013): a typed question, decision, approval_request or message with `awaiting` stops waiting
  only when the recipient replies (`in_reply_to`), not when it is read or ages; `tether_pending_replies` lists each with
  `created_at`. Plain updates and messages never wait.
