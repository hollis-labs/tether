- Events: Tether emits `session.usage` (CW-20261016-0139, X4d) per architect ruling `session_usage_and_health_kinds_2026_10_16`: after every finished turn, completed or failed, a cumulative-totals report (`input_tokens`, `output_tokens`, `turns`, `source: provider`, plus the `turn_id`), and once at session end with `final: true`. Never periodic. A session whose runtime never reports tokens emits nothing, because zero totals would claim a measurement nobody made; Tether does not estimate. No cost fields (cost belongs to the usage ledger). `session.health_changed` is registered as a kind but not emitted yet.
