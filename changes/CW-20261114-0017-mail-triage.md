- Hub mail triage before wake (CW-20261114-0017): for a seat with `mail_triage` on (`catalog.defaults.mail_triage`,
  per-agent override; off by default), each message is classified once as `human` (wakes now), `action` (wakes at most
  once per `action_interval`, default 3m; later ones are deferred, and a wake covers the seat's other pending action
  mail), `fyi` (no wake; one line on the seat's next human-originated turn, typed fyi then marked read) or `read` (no
  wake; a typed `attention: none` envelope is marked read by the hub). Each message gets a `mail.triaged` event. Wakes
  made when mail is stored are now recorded as `mail_wake` turn inputs. Migration 0101 adds `wake_triage` and
  `seat_wake_clock`. See `docs/mail-triage.md`.
