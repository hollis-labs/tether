- `tether sessions reap-ghosts` cleans up ghost state (CW-20261114-0007): sessions that claim to run on a connected
  worker that no longer holds them (trusted only from workers whose hello proves a complete inventory), on a worker gone
  7 days, or hub-local orphans with nothing alive; hub-local shim custody of ended sessions with nothing alive; and
  worker rows unseen for 7 days, which are retired (hidden, `superseded_by` the live row of their label), never
  deleted. Dry run by default; `--apply` needs `--backup` naming a SQLite backup written within 2 hours. Closing a ghost
  revokes its credential, bindings and agent tokens. Worker label lookups now pick the newest unretired enrollment (a stale duplicate could win before). See
  docs/ghost-cleanup-runbook.md.
