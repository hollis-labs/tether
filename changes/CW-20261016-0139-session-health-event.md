- Events: Tether emits `session.health_changed` (CW-20261016-0139, X4d) on a session's health transition only, derived from signals it already publishes: running, `session.stalled`, `provider.session_lost`, a finished turn's output, a failed or orphaned end, and a shim left with an unknown outcome. Reasons are closed codes (`session_running`, `repeated_tool_denials`, `provider_session_lost`, `turn_output_resumed`, `runtime_stopped`, `shim_outcome_unknown`, `tracker_restart`); `unhealthy` is final for the session; a clean end changes nothing; no inactivity threshold is used. The tracker is in memory, so after a restart the first transition per session starts from `unknown` and carries `tracker_restart`. The event bus also gains observers, called after a publish outside the bus lock.
