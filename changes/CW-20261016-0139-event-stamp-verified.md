- Events: Tether now stamps events from verified context (CW-20261016-0139, X4b). Every event carries the environment id, authority and host once the daemon knows them. An event about a session whose caller resolved (session credential or issued session-bound token with a confirmed registry binding) also carries agent URN, workstream, task, launch, project and logical agent; the trace and span ids come from the current span. The actor is stamped only for the real local operator or a confirmed agent session; an operator-minted narrow token, a claimed session and unverified callers get none. Anything unverifiable is left empty, never guessed, and a value a producer already set is never overwritten.
