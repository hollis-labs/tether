- CW-20261017-0047: The worker's manual-agent activity scan now reads the pulse directory named after the worker's own label (the name the hub reports for the machine), not just `TETHER_PULSE_MACHINE` or the hostname. Hooks started where that variable is not exported (a Codex or Agy session launched from a terminal) used to write under the hostname, a directory the worker never scanned, so those sessions never reached the hub. Precedence is `TETHER_PULSE_MACHINE`, then the worker label, then the short hostname; a label that is not a plain name falls back to the hostname. `tether-worker activity` follows the same rule. A machine whose label equals its hostname behaves as before, and a worker no longer needs `TETHER_PULSE_MACHINE` in its Outpost plugin environment.
