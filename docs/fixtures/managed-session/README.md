# Managed-session contract fixtures

Companion to `docs/managed-session-contract.md` (CW-20261021-0001).

| Path | What it is | Backed by code |
|---|---|---|
| `snapshot.json` | environment snapshot: one session per lifecycle/work-state/pending variant | **yes**: generated by `TestContractFixturesSnapshot` from the real types |
| `session-awaiting-approval.json` | one session item (the single-session snapshot has the same shape with one session) | **yes** |
| `events/*.json` | one SSE `data:` object per kind | **yes**: generated by `TestContractFixturesEvents` through `Map` |
| `frames/*.sse` | the exact SSE frames: event, `synchronized`, `gap` (purged, too_large, ahead, restart) | **yes**: recorded from the real stream handler |
| `schema/*.schema.json` | JSON Schema 2020-12 for the session, the snapshot and the event envelope | validated against every file above by `TestContractFixturesValidate` |
| `proposed/*.json` | the PROPOSED additions (connectivity, freshness, operations, provider/worker/project, `session.projection_changed`) | **no**: schema-valid examples only; they move to generated fixtures when CW-20261021-0003/0004 ship |

Regenerate the generated files after an intentional change with
`UPDATE_FIXTURES=1 go test ./internal/environmentstream -run ContractFixtures`.
The tests fail if a file differs from the code's output, so these cannot drift.
