# Planning Notes

This directory is the maintainers' planning and execution archive.

It is intentionally kept in the repository because it captures roadmap,
sprint, ADR-adjacent rationale, and historical implementation context that is
still useful to maintainers.

Important boundaries:

- Treat `docs/` as the public product and operator documentation surface.
- Treat `planning/` as internal project history, draft specs, and execution
  notes.
- Older files may still use the historical "Agent Mux" name or reference
  superseded surfaces such as the deleted TUI. Those references are historical,
  not current product guidance.

If a document in `planning/` graduates into release-facing guidance, move or
rewrite it under `docs/` rather than linking users directly into this tree.
